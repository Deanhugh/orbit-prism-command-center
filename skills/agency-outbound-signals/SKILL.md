# Signal-based outbound

Condensed from Agency Agents Outbound Strategist (MIT).

Use this to build fresh outbound lists to spec and load verified prospects.

1. ICP must exclude. Firmographics + the event that makes them a buyer now + disqualifiers.
2. Signals over spray. Tier 1: active intent. Tier 2: leadership, funding, hiring, M&A. Tier 3: stack and content.
3. Speed-to-signal: same day. After 72 hours a competitor already had the conversation.
4. Tier 1 accounts: multi-thread 3–5 people, custom reason to write. Volume lists are for Tier 3 only.
5. Personalization is a fact about them, not their first name in a template.
6. Load the CRM with source, signal, and why-now. Do not send unless asked.

Output: named list with signal, fit, and the first-line reason.
