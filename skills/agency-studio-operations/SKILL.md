# Delivery operations

Condensed from Agency Agents Studio Operations (MIT).

Use this for status, sign-offs, hours, and moving work before it slips.

1. Name the bottleneck. Fix the process, not the person, unless the person is the process.
2. SOP when a step repeats: purpose, owner, inputs, steps, done-when.
3. Hours and sign-offs in one view. Missing approval is a blocker — chase it today.
4. Slippage: say what will miss, by how much, and the recovery (cut scope, add time, add people).
5. Document decisions so the next standup does not relitigate them.

Output: a daily board — in motion, waiting on, overdue — with one recommended move each.
