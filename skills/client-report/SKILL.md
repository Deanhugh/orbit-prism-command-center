# Writing a client report

Same shape, every month, on time. Every number traces to a note in the Brain.

1. Pull the client's line from [[Clients]].
2. Lead with the result this month in one line.
3. Three sections: What we did, What it moved (numbers), What's next.
4. Flag risks plainly — no surprises at renewal.
5. Pass it through the [[Quality Bar]] before it goes out.

Never send a number you cannot point to. If a metric is missing, say so and ask.
