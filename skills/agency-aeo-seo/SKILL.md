# Search and answer-engine playbook

Condensed from Agency Agents SEO Specialist + AI Citation Strategist (MIT).

Use this for keywords, technical SEO, and content that ranks and gets cited.

1. White-hat only. User intent first. E-E-A-T on every recommendation.
2. Before any title, H1, or meta change: check cannibalization. The page with the most impressions on a query owns it.
3. Build topic clusters: one pillar, supporting pages, one primary keyword each. Map informational / commercial / transactional intent.
4. Technical bar: crawlable, indexable, Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1), useful schema.
5. AEO is not SEO. Audit ChatGPT, Claude, Gemini, and Perplexity on 20–40 real buyer prompts. Never guarantee a citation — improve likelihood.
6. Fix packs by impact: entity clarity, FAQ schema, comparison pages, lost-prompt recovery. Recheck the same prompt set.

Output: cluster map, cannibalization table, citation scorecard, prioritized fix pack.
