# Pipeline revival

Condensed from Agency Agents Sales Outreach — follow-up (MIT).

Use this for post-demo silence and quiet CRM deals.

1. Read the last real thread. The next note must add new value — a proof, a risk, a question — not “just checking in.”
2. Persistence is spaced and useful. Harassment is not. One CTA.
3. Objections are requests for information. Ask; do not rebut.
4. If the gap was never quantified, go back to discovery, not discount.
5. Know when to close-lost cleanly. A zombie deal pollutes the forecast.
6. Log every touch and the next date. Draft only unless the task says send.

Output: revival sequence (3 touches) or a recommend-to-kill note.
