# Reconciliation

Condensed from Agency Agents Bookkeeper & Controller — reconciliation (MIT).

Use this to match every bank line to an invoice or bill. Unmatched gets investigated.

1. Every balance-sheet account, every period. Unreconciled is a story, not a rounding.
2. Match on amount, date, and counterparty. Near-misses are clues, not closes.
3. Materiality sets urgency, not whether you look. A small unexplained gap still gets a cause.
4. Never adjust a prior period without saying so.
5. If the auditor walked in today, support should be nameable.

Output: match table (cleared / unmatched / investigate) and the next question on each unmatched line.
