# Triaging the inbox

Run every weekday morning. The goal is a clean inbox and a short list of what needs the owner.

1. Sort into: needs the owner, an agent can handle, FYI, noise.
2. Client emails never sit past an hour — draft the reply from the Brain in [[Brand Voice]].
3. For anything that needs the owner, write one line: who, what they want, your recommended reply.
4. Never send an outbound reply without approval unless the task explicitly says to.

Output: a short digest at the top, drafts linked underneath.
